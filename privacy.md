# Privacy Policy – Query Bot Analyst Command Center

Effective Date: October 2026

## Overview

Query Bot Analyst Command Center is a productivity extension designed to help users access SQL query libraries, reference materials, business resources, workspace tools, and workflow automation features directly within Google Chrome.

We are committed to protecting user privacy and minimizing data collection.

## Information We Collect

The extension may store the following information locally within the user's browser:

- User preferences and settings
- Saved queries
- Favorites and bookmarks
- Custom notes entered by the user
- Workspace configuration
- Resource library selections
- User-created content

This information is stored locally using Chrome's storage APIs.

## Information We Do Not Collect

The extension does not:

- Sell personal information
- Share personal information with third parties
- Use personal information for advertising
- Track users across websites
- Collect browsing history for marketing purposes
- Collect sensitive personal information unless explicitly entered by the user into extension features

## Website Access

The extension may access webpage content on approved websites solely to provide requested functionality, including:

- Contextual workflow assistance
- Resource integration
- Page analysis
- User-initiated automation
- Data extraction required for extension features

Page content is only accessed as necessary for the extension's functionality.

## Data Storage

User data is stored locally within Chrome using the browser's storage APIs.

If optional synchronization features are enabled by the user, information may be stored using services selected and authorized by the user.

## Data Sharing

No user data is sold, rented, licensed, or shared with advertisers.

Information is only transmitted when necessary to perform a user-requested action or access a user-authorized service.

## Security

Reasonable measures are taken to protect data stored by the extension. However, users remain responsible for securing their own devices and browser profiles.

## Children's Privacy

This extension is not intended for children under 13 years of age.

## Changes to This Policy

This privacy policy may be updated periodically. Any updates will be reflected in a revised version of this document.

## Contact

For questions regarding this privacy policy, users may contact the extension developer through the contact information provided on the Chrome Web Store listing.
